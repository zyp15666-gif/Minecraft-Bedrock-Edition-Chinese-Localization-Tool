# 使用指南

## 快速开始

### 1. 系统要求
- **操作系统**：Windows 10 1909+ 或 Windows 11
- **运行时**：Microsoft Edge WebView2 运行时（应用启动时会自动检测）
- **Python**：3.9+（如果从源码运行）

### 2. 安装

#### 方式一：使用安装包（推荐）
1. 下载最新版本的安装包（`MinecraftBedrockLocalizerSetup_vX.X.X.exe`）
2. 运行安装程序
3. 安装完成后，从开始菜单或桌面快捷方式启动

#### 方式二：从源码运行
1. 克隆或下载项目源码
2. 安装依赖：`pip install -r requirements.txt`
3. 运行：`python scripts/run_flet_desktop.py`

### 3. 首次启动
应用启动时会自动：
- 检测 WebView2 运行时（如缺失会提示安装）
- 初始化日志系统
- 后台检查更新
- 加载配置文件

### 4. 配置 API
1. 打开应用后，点击顶部的 "配置" 标签
2. 点击 "添加 API" 按钮
3. 选择 API 类型（智谱、DeepSeek、通义千问、豆包、本地 Ollama、OpenAI、Azure、百度、讯飞、Gemini）
4. 输入 API 密钥和其他信息
5. 点击 "保存" 按钮

**安全提示**：API 密钥会使用 Windows DPAPI 加密存储，不会以明文形式保存在配置文件中。

## 系统设置

### 主题切换
- 点击顶部的 "主题切换" 按钮在亮色和暗色主题之间切换
- 应用会自动检测系统高对比度模式并适配

### 查看日志
- 点击顶部的 "日志" 标签查看操作日志
- 日志文件保存在 `Documents\Minecraft基岩版汉化工具\logs\`

### 导入/导出配置
- 在配置标签页中，可以导入或导出配置文件
- 导出的配置文件不包含 API 密钥（安全考虑）

## 安全特性

### API 密钥安全存储
- API 密钥使用 Windows DPAPI 加密存储
- 加密后的密钥只能由当前 Windows 用户账户解密
- 配置文件中的 API 密钥显示为 `<SECURE:provider_name>` 占位符

### 配置版本迁移
- 配置文件支持自动版本迁移
- 当前配置版本：2.1
- 升级时自动迁移旧配置

### 数据完整性保护
- SQLite 缓存启动时自动检查完整性
- 损坏的缓存会自动备份并重建
- 配置保存使用原子写入，避免损坏

## 常见问题

### Q: 启动时提示缺少 WebView2？
A: 应用会自动打开下载页面，安装完成后重新启动即可。

### Q: API 检测失败怎么办？
A: 检查 API 密钥是否正确，网络连接是否正常，以及 API 提供商是否服务正常。

### Q: 翻译速度很慢怎么办？
A: 可以在配置中增加 `max_workers` 值，或使用多个 API 密钥提高并发能力。

### Q: 翻译结果不准确怎么办？
A: 可以尝试使用不同的 API 模型，或调整翻译提示词。

### Q: 应用崩溃怎么办？
A: 查看 `Documents\Minecraft基岩版汉化工具\logs` 目录中的崩溃日志，然后联系开发者。

### Q: 杀毒软件报警怎么办？
A: 这是 PyInstaller 打包程序的常见问题。请参考 `docs/CODE_SIGNING_GUIDE.md` 了解详情。

### Q: 如何检查更新？
A: 应用启动时会自动检查更新。也可以手动访问 GitHub Releases 页面。

## 性能优化

1. **使用多线程**：确保配置中的 `use_multithreading` 为 `true`
2. **增加线程数**：根据电脑性能调整 `max_workers` 值
3. **使用多个 API**：添加多个 API 密钥提高并发能力
4. **合理设置速率限制**：根据 API 提供商的限制调整 `rate_limit` 值

## 备份与恢复

- 应用会自动备份修改的文件夹
- 备份文件存储在原文件夹的同级目录，命名为 `backup_日期时间`
- 如果操作出现问题，可以从备份中恢复
- 卸载应用时会询问是否删除用户数据

## 可访问性支持

应用支持以下可访问性特性：
- 自动检测系统高对比度模式
- 自动检测屏幕阅读器（NVDA、Windows 讲述人）
- 支持系统文本缩放

## 技术特性

### 智能翻译策略
- **三阶段翻译**：自动处理颜色代码、占位符和游戏术语
- **质量检查**：自动检测翻译质量问题
- **术语一致性**：内置 1551 条 Minecraft 术语

### 模块化架构
- **翻译管道**：统一的翻译接口
- **质量检查器**：独立的翻译质量检查模块
- **依赖注入容器**：统一初始化入口

### 性能优化
- **分批处理**：智能分批避免 API 速率限制
- **多 API 负载均衡**：自动检测可用 API，平衡负载
- **缓存系统**：内存 LRU + SQLite WAL 双层缓存

## 配置文件说明

配置文件位于 `config/config.yml`，主要配置项：

```yaml
# 翻译设置
translation:
  use_multithreading: true
  max_workers: 4
  batch_size: 50
  batch_delay: 1.0

# API 配置
deepseek:
  - name: "my-deepseek"
    api_key: "<SECURE:deepseek>"
    model: "deepseek-chat"
    enabled: true

# 启动设置
startup_animation_duration: 0.8
```

更多技术细节请参考 [API文档](./API.md)。
